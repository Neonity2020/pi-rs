# 内置工具系统与安全边界

pi-rs 实现了与上游 pi 完全兼容的 7 项核心内置工具。所有工具实现 `pi_agent::AgentTool` trait。

## 工具清单与参数规范

### 1. read

读取本地文本文件，提供行号并在大文件时自动截断。

- 参数：
  - `path` (string, 必需)：文件相对或绝对路径。
  - `offset` (number, 可选)：起始读取行号（1-indexed）。
  - `limit` (number, 可选)：最大读取行数。
- 限制：默认单次最大返回行数和字节限制，超出部分截断并提示。

### 2. write

覆盖或创建文件内容。

- 参数：
  - `path` (string, 必需)：写入的目标路径。
  - `content` (string, 必需)：文件完整内容。
- 保证：自动创建父级目录。

### 3. edit

基于精准子串匹配的文件局部替换。

- 参数：
  - `path` (string, 必需)：目标文件路径。
  - `edits` (array, 必需)：替换项数组，每项包含 `oldText` 和 `newText`。
- 保护：若 `oldText` 在文件中未找到或出现多次，操作拒绝执行并返回明确错误，防止歧义替换损坏代码。

### 4. bash

在本机执行 shell 命令，不提供沙箱隔离。

- 参数：
  - `command` (string, 必需)：需要执行的 Bash 脚本字符串。
  - `timeout` (number, 可选)：超时时间（秒，默认不限制）。
- 保证：
  - Unix 上创建独立进程组，超时或取消时终止仍在该组内的子进程。
  - 管道防挂死：子进程退出后启动 100ms 静默宽限期，避免孤儿后代持有管道导致主线程挂起。
  - 截断后的完整输出保存在私有临时目录；创建新归档时清理超过 24 小时未修改的旧归档，当前进程创建的归档在进程运行期间保留。

### 5. grep

基于正则表达式的文件内容匹配。

- 参数：
  - `pattern` (string, 必需)：Rust 正则表达式。
  - `path` (string, 可选)：搜索起始目录（默认当前工作区）。
  - `include` (string, 可选)：文件名 glob 过滤规则。
- 默认排除：自动跳过 `.git`、`node_modules`、`target` 等大型临时/编译目录。

### 6. find

基于 glob 模式的文件名搜索。

- 参数：
  - `pattern` (string, 必需)：glob 文件匹配模式（如 `*.rs`）。
  - `path` (string, 可选)：搜索目录根节点。

### 7. ls

列出指定目录结构和元信息。

- 参数：
  - `path` (string, 可选)：目录路径（默认当前目录）。
  - `depth` (number, 可选)：遍历最大深度。

## 安全与权限控制

- 工具执行均通过 `EnvConnection` 接口抽象，目前使用 `LocalConnection`。
- 运行模型生成的任意 shell 命令和代码覆写时，务必在可信测试工作区中执行。
