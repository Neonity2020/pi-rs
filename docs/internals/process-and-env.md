# 进程生命周期与环境执行

`pi-env` 提供统一的环境连接抽象 (`EnvConnection`)，本地实现位于 `crates/pi-env/src/local.rs`。

## 进程组隔离 (Process Group Isolation)

在执行任意 shell 脚本命令（如 `bash` 工具）时，pi-env 在启动子进程前通过系统调用建立独立进程组：

- **Unix 平台**：
  - 子进程创建前设置 `setpgid(0, 0)`，使其成为独立进程组的 leader。
  - 任务被用户中止（`Esc`）或触发超时时，向整个进程组广播 `SIGKILL`（`killpg(pgid, SIGKILL)`）。
  - 保护范围：覆盖同进程组内的所有派生子进程。
  - 边界与限制：主动调用 `setsid()` 逃逸或脱离该进程组的后台孤儿后代进程不受管理。
- **非 Unix 平台**：
  - 降级为直接终止主子进程句柄。

## 管道滞留排空与 100ms 宽限机制

### 问题场景
当用户命令派生了后台进程（如 `sh -c 'sleep 5 & echo ok'`），主 shell 虽然立即退出，但后台派生进程可能仍然继承并持有标准输出/错误管道的写端句柄。如果主程序盲目等待管道返回 `EOF`，执行将被无故挂起数秒甚至超时。

### 解决方案
`pi-env` 移植上游 `waitForChildProcess` 的异步处理语义：
1. 捕获任务拆分为共享缓冲与后台异步读流任务 (`Capture`)。
2. 当主子进程退出状态返回时，若管道写端依然被未退出的后代进程持有：
   - 启动 100ms 静默倒计时（Silence Grace Window）。
   - 在此窗口内，若管道有新数据到达，即重置计时器并追加至输出。
   - 一旦连续 100ms 无数据输入，视为主进程有效输出已排空，立即用当前已捕获的缓冲区收尾并返回结果，不被孤儿进程阻塞。
